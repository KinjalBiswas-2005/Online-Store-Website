🛒 Online Store Website

This is a task from SPCL Infotech Services Pvt.Ltd. to design and develop a dynamic and responsive online store homepage. The website has features categorized into product listings displayed as cards and included filter functionality for sorting products by categories and price.

📌 Project Overview

A simple and responsive online store website built using HTML, CSS, and JavaScript. This project displays varieties of products, allows users to browse items, and provides a basic shopping experience.

🚀 Features

🏬 Product listing with images, names, product details and prices

🔍 Search functionality

🛍️ Add to cart feature

📱 Fully responsive design (mobile-friendly)

🎨 Clean and modern UI

🛠️ Technologies Used

1.HTML5 – Structure of the website

2.CSS3 – Styling and layout

3.JavaScript (Vanilla JS) – Functionality and interactivity

4.API (Fakestore API) - For fetching different product and product details
